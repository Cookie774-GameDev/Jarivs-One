# SiYuan corresponding source offer

VibeSpace's Windows package includes an unmodified runtime closure from SiYuan v3.8.1, licensed under the GNU Affero General Public License version 3. The included runtime is pinned to upstream commit `afa823b6b4e4f183511e0bc0a3be93caa94c7c97`.

The complete corresponding source is available from the official upstream repository and exact release tag:

- Repository: <https://github.com/siyuan-note/siyuan>
- Exact source: <https://github.com/siyuan-note/siyuan/tree/v3.8.1>
- Source archive: <https://github.com/siyuan-note/siyuan/archive/refs/tags/v3.8.1.tar.gz>
- License: <https://github.com/siyuan-note/siyuan/blob/v3.8.1/LICENSE>
- Build and packaging instructions: <https://github.com/siyuan-note/siyuan/tree/v3.8.1/scripts>

The packaged closure contains the official SiYuan kernel, stage UI, appearance assets, guides, changelogs, Pandoc runtime/resources, upstream AGPL license, and upstream third-party notices. The upstream Electron shell is excluded because VibeSpace supplies the Tauri desktop shell. VibeSpace's integration code is distributed in the VibeSpace source repository; no claim is made here that an external legal review has completed.
