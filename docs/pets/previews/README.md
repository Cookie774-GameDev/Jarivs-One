- redact usernames and absolute machine paths;
- exclude tokens, API keys, secrets, real prompts, customer data, billing/auth screens, and connected-service content;
- show only the intended Pet panel, terminal Fleet, navigation, or resource interaction behavior;
- record the exact app commit, capture command, dimensions, and manual observations;
- inspect every frame before staging the exact media files.
