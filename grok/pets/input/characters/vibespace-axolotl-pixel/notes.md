# VibeSpace Axolotl immutable source package

This directory is a versioned, byte-for-byte copy of the supplied layered Axolotl package. The original files remain at `C:\Users\viper\Downloads\VibeSpaceOs` and must never be overwritten by the Pet build pipeline.

The PSD, ORA, original manifest, original layer archive, original quality report, 136 extracted full-canvas PNG layers, supplied previews, assembly scripts, V logo, and original flat source are archival inputs. Derived processing writes only to the application asset output tree.

`archival/source-hashes.json` inventories source-package inputs before derived processing. `archival/vibespace_axolotl_layered_package.zip` is the deterministic complete normalized package and intentionally excludes itself. The supplied happy expression remains the authoritative expression reference, and all V-mark layers are non-mirrorable.

The catalog ID is `vibespace-axolotl-pixel`. The supplied layered manifest retains its original internal character ID, `vibespace-axolotl-light`, for archival fidelity.
