Architecture

Local-first. BYOK. Open-source core. Built to last.

Desktop

Tauri 2, Rust, React, TypeScript, Vite, Tailwind, tiny native installers.

Local-first chats, tasks, settings, skills, agents, and memory. Cloud sync optional.

FAQ

Questions before you install

Is VibeSpace only for coding?

No. Coding is the sharpest use-case, but VibeSpace also handles research, calls, tasks, memory, skills, agents, notes, actions, and project context.

What models work today?

Anthropic, OpenAI, Google Gemini, Groq, and Ollama are live adapters. Other providers have UI and key persistence wired and can be promoted as adapters ship.

Is Jarvis voice the same as a phone call?

No. Jarvis voice is the in-app hands-free assistant (local Kokoro, free, unlimited). AI calling is a separate feature — PSTN phone calls via Twilio on paid tiers, or free in-app WebRTC via LiveKit.

What is new in v0.1.47?

Unified skills catalog with SkillEditor and /skills picker, Inspector panel (Today, Quick Launch, Context, Tools Run, Trace milestones, Active Work), milestone-driven Kanban, terminal agent coordination with a Rust-backed ledger, and an Apex billing tier.

Can it run offline?

Yes. Offline mode routes chat to Ollama. Local model support is live and keyless. Local Kokoro voice is always free and unlimited.

What is the official website?

The official home is vibespaceos.com. Downloads and one-line installers always resolve through the GitHub releases page, so both stay in sync.
