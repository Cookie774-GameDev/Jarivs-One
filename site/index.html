THE USEFUL DETAILS

Before you
make yourself at home.

What exactly is VibeSpace?+

VibeSpace is the local-first desktop workspace. Jarvis is the assistant inside it. Models, agents, terminals, voice, tasks, skills and memory stay connected to your projects.

Can I use my own models?+

Yes. Bring your own provider keys, or use supported local models through Ollama. Provider adapters and model availability can vary by release.

Is the app available yet?+

The app is coming soon. This site previews the product and documents the plan catalog. Payments are opening later; no checkout is available here.

What will getting started involve?+

When the app launches: create or verify your account, review Access status, and add optional AI providers. The introductory Access trial and separate feature-plan charges are described above.

Does everything stay on my machine?+

Chats, tasks, settings, schedules and memory are local by default. API keys use the operating-system keychain. Using a cloud model sends the selected request and context to that provider. Cloud sync is optional.

Do agents run commands without asking?+

Destructive actions and multi-terminal orchestration plans require approval. Declining leaves the action unrun. The demonstrations on this website never execute commands.

Which platforms does VibeSpace target?+

Windows, macOS and Linux. The desktop shell uses Tauri 2 and Rust; the open-source core is available under Apache-2.0. Release readiness varies by platform.
