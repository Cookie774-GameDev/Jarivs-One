The charges stay separate

Required after trial VibeSpace Access

Controls whether an eligible public account can continue actively using VibeSpace after its access trial. It does not include paid AI, voice, or cloud usage.

Optional Feature plan

Covers the AI, voice, cloud, or usage allowance listed for that plan. It does not replace the Access subscription.

Two separate subscriptions may appear on your billing statement. The Access trial does not make an existing or future paid feature plan free.

Introductory trial terms

  • The introductory access trial starts on first use with a verified account and lasts 30 consecutive days.
  • The trial applies only to VibeSpace Access; no paid feature tier is included.
  • The trial does not collect payment or start a subscription. It does not auto-convert.
  • When the trial or any grace period ends, continued use requires you to deliberately start the separate $20/month Access subscription.
  • Only a purchased subscription renews monthly until canceled.
  • Your server-confirmed status in the desktop app is authoritative. A website URL, screenshot, or checkout return page does not grant access.

Eligibility, trial start, grace status, renewal date for a purchased subscription, tax, and current status are shown in the authenticated desktop billing surface before a billing action. Review that information before continuing.

Access FAQ

Is VibeSpace Access an AI plan?

No. Access is the base application-access product. Optional AI, voice, and cloud plans are separate feature products.

Does the 30-day trial include paid feature usage?

No. The trial covers only VibeSpace Access and does not grant a paid AI, voice, or cloud plan.

Can I use BYOK or local providers?

VibeSpace supports bring-your-own-key and local-provider workflows. Access is still the separate base application subscription after the trial.

Can this website show whether my Access is active?

No. This public page has no authenticated account state. Check Settings → Billing & Access in the VibeSpace desktop app.

What happens if checkout is interrupted?

Return to the desktop billing surface and refresh the server-confirmed status. Do not treat a return page as proof that Access changed.
