# VibeSpace Remotion Trailer

A 36-second, 1920×1080, 30fps cinematic product trailer built from the VibeSpace repository's own creative direction and demo script.

## Story arc

1. **Create together. Play together.** — brand reveal
2. **Command Center** — terminals, Jarvis, and Hive orchestration
3. **Jarvis Voice** — local speech, live captions, and project context
4. **Agent Council** — ten agents sharing one context map
5. **VibeSpace Phone** — incoming AI call and synced build status
6. **Feature system** — terminals, voice, context, privacy, skills, open source
7. **Finale** — open-source CTA

## Commands

```bash
npm install
npm run studio
npm run render
npm run poster
```

The original soundtrack is synthesized locally by `scripts/generate-score.mjs`; no third-party music or stock footage is used.

## Output

- `out/vibespace-remotion-trailer.mp4`
- `out/vibespace-remotion-poster.png`
